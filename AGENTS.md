# Project Instructions

This is a frontend project for a cinema scheduling system.

## Tech Stack
- React
- TypeScript
- Vite
- MUI
- React Router
- Axios

## Rules
- Use TypeScript.
- Use MUI components for UI.
- Keep code clean and modular.
- Do not put all logic inside App.tsx.
- Use pages, components, services, api, types folders.
- Do not change backend API behavior.
- Do not implement features not requested.

## Backend
Backend base URL:
http://localhost:8080

Existing APIs:
- GET /api/employees
- GET /api/positions
- GET /api/availability
- GET /api/weekly-schedules
- GET /api/position-requirements
- GET /api/schedule-assignments

## First Priority
Build layout and pages first.
Then connect employee API.
